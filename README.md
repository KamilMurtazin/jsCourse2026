# SdCourseJs

Учебный курс по JavaScript, Vue 3, Pinia и Vite.

## Необходимые инструменты

- Node.js `^22.22.2`, `^24.15.0` или `>=26.0.0`;
- Yarn 1.22;
- Git.

Проверьте установленные версии:

```bash
node --version
yarn --version
```

## Быстрый старт

Установите зависимости из `yarn.lock` и запустите учебное приложение:

```bash
yarn install --frozen-lockfile
yarn watch
```

Vite выведет локальный адрес приложения в терминал.

Другие служебные команды:

```bash
yarn build
yarn type-checker
yarn lint
yarn lint:fix
```

## Своя ветка

Создайте ветку от актуальной ветки `main` и опубликуйте её:

```bash
git pull
git checkout -b <фамилия> origin/main
git push -u origin <фамилия>
```

Получить новые материалы курса и объединить их со своей веткой:

```bash
yarn update
git push
```

Перед обновлением зафиксируйте собственные изменения коммитом.

## Работа с заданиями

После решения задания сохраните результат:

```bash
git add .
git commit -m "Урок <N>. Задача <M>. Краткое описание"
```

### Тесты одной лекции

Основной способ проверки — запуск тестов только для текущей лекции:

```bash
yarn test "Lessons/01."
```

Автоматически перезапускать тесты этой лекции после изменений:

```bash
yarn test-watch "Lessons/01."
```

Чтобы дополнительно отфильтровать тесты по названию задачи, передайте стандартный аргумент
Vitest `-t`:

```bash
yarn test "Lessons/01." -t 01.c.0
yarn test-watch "Lessons/01." -t 01.c.0
```

Запуск всех тестов:

```bash
yarn test
```

Без аргументов команда `yarn test` запускает полный набор проверок всего курса.

Подробная инструкция: [Работа с тестами](./WiKi/Тесты.md).
