# Учебная мастерская

Страница `/src/index.html` предназначена для студентов второго курса, начинающих изучать
программирование, и для демонстрации решений преподавателем. Она показывает условие,
текущий файл и результат выполнения. Решения редактируются в обычном редакторе проекта.
Аккаунты, сервер хранения решений и редактор кода в браузере не требуются.

## Работа студента

1. Запустите `yarn watch` и откройте адрес `/src/index.html`, указанный Vite.
2. Выберите урок. «Материалы урока» показывают его README; список ниже содержит практику,
   домашние задания и доступные варианты JS/TS, HTML и Vue.
3. Выберите задачу: она автоматически запустится. Измените решение в редакторе и сохраните
   файл. Vite обновит исходник и результат. На статической сборке после редактирования нужна новая сборка.
4. Для функции задайте аргументы: `42, "текст", [1, 2], {"name": "Анна"}`.
   Это четыре аргумента. `[1, 2]` отдельно — один аргумент-массив, `1, 2` — два числа.
   Строки требуют двойных кавычек JSON. Пустое поле использует экспортированный массив
   `payload`, затем `window.payload` внутри окружения задачи, затем пустой массив аргументов.
5. Нажмите «Запустить», Enter в поле аргументов или Ctrl/⌘+Enter. Неверный JSON показывает
   ошибку возле поля и не запускает код. Введённые аргументы не исчезают после запуска.
6. Посмотрите консоль: доступны `log`, `info`, `warn`, `error`, результат и время вызова.
   `0`, `false`, пустая строка, `null` и `undefined` выводятся явно. Promise ожидается;
   исключения и необработанные отклонения Promise отображаются как ошибки.
7. Откройте «Как проверить решение тестами» и скопируйте команду в терминал проекта.
   «Вызов завершён» означает только завершение вызова, а не правильность решения.

Аргументы, последняя задача и заметки хранятся в localStorage этого браузера. Это не
синхронизация и не резервная копия. Явная ссылка с `lesson`/`task` имеет приоритет над
сохранённой задачей. Работают кнопки браузера «Назад»/«Вперёд». Неизвестная задача в ссылке
не запускает старое решение и предлагает выбрать существующую.

## Демонстрация и объяснение

- **Разбор по строкам**: нажмите строку или одноимённую кнопку. Перемещайтесь кнопками ↑/↓
  либо стрелками клавиатуры, когда фокус вне поля ввода. Для каждой строки можно записать
  своё объяснение. Это последовательное чтение текста, а не трассировка выполнения:
  циклы не повторяют строки, значения переменных не вычисляются. Заметки привязаны к
  пути файла и номеру строки; после вставки строк их следует проверить.
- **Режим показа**: скрывает список задач, увеличивает условие, код и результат. Escape
  возвращает обычный вид. Предыдущая/следующая задача остаются доступны в заголовке.
- **Отладка JS/TS**: откройте DevTools (обычно F12), нажмите «Отладка». Браузер остановится
  перед вызовом. F11 позволяет войти в функцию задачи, F10 сделать шаг, F8 продолжить.
  Переменные смотрите в Scope; точки останова ставьте в Sources в исходном файле задачи.
  Без открытых DevTools эта кнопка выполняет обычный запуск. Для HTML/Vue используйте
  точки останова DevTools в скриптах/компонентах и затем «Запустить».

«Отладка» использует встроенный отладчик браузера: отдельный интерпретатор или имитация
переменных в приложении не нужны. Для работы отладки в сборке сохранены `debugger`,
читаемый JavaScript и source maps. Это увеличивает размер сборки, что приемлемо для
локального учебного инструмента.

## Форматы задач

Каталог строится из `Lessons/<урок>/README.md` и папок `Tasks` / `Homework`.
Имя задачи: `Task <номер>. <название>`.

| Файл | Поведение |
| --- | --- |
| `index.js` / `index.ts` | Вызов `export default` как функции; для `class` используется `new`. Необязательный `export const payload = [...]` задаёт аргументы. |
| `index.html` / `src/index.html` | Отдельная HTML-страница со своими скриптами, DOM и стилями. Скрипты страницы сами определяют инициализацию. |
| `Example/index.html` | Отдельный вариант «Пример», не смешанный с решением. |
| `App.vue` | Отдельное Vue-приложение с новым экземпляром Pinia. |
| `README.md` | Условие для всех вариантов задачи; отсутствие файла не ломает каталог. |

Если функция работает с DOM, выбирайте HTML-вариант. В JS-варианте произвольной разметки
из HTML нет; интерфейс предлагает ссылку на HTML той же задачи. Исходник HTML-варианта
показывает сам HTML; исходник функции доступен в JS-варианте.

Для задач с импортами `fs`, `path`, `node:*` и другими распознаваемыми Node-модулями
показывается пояснение и команда тестов. Такие задачи нужно выполнять в Node.js.
Проверка по тексту исходника — подсказка для текущего курса, не анализ всех транзитивных
зависимостей. Неизвестная браузеру зависимость всё равно может дать ошибку при импорте.

## Устройство и ограничения

- `src/initApp.ts` монтирует корневое приложение и возвращает функцию размонтирования.
  Навигацией, материалами и запуском управляет `src/utils/useCourse.ts`; отображением —
  `src/views/LessonApp.vue`. Прямые DOM-обработчики и глобальная подмена консоли удалены.
- Каталог загружает текст лениво. Номер загрузки исключает попадание запоздалого условия
  или исходника в новую задачу. Ошибки исходника и README обрабатываются отдельно.
- Каждый запуск создаёт новый iframe. Повторный запуск, смена задачи и «Остановить»
  удаляют старые таймеры, обработчики, DOM и Vue/Pinia вместе с окружением.
- `src/runner/bridge.ts` передаёт сообщения только из iframe; родитель проверяет источник,
  origin и идентификатор запуска. Консоль ограничена 500 сообщениями на запуск и размером
  одного сообщения. Объекты снимаются на момент вывода, а не показываются как живые ссылки.
- **Iframe не является защищённой средой для чужого кода**: задачи выполняются на том же
  origin и предназначены для доверенного локального курса. Синхронный бесконечный цикл
  может заблокировать поток браузера вместе с кнопкой остановки. Полная защита от него
  потребовала бы отдельного исполнения, несовместимого с произвольными DOM/Vue-задачами.
- Через 10 секунд незавершённого вызова появляется пояснение. Это не принудительный таймаут:
  Promise может ждать сеть, пользовательское действие или продолжение в отладчике.
- HTML-статус сообщает о загрузке документа; последующие ошибки JavaScript попадают в
  консоль. Это не проверка корректности внешнего API, каждого ресурса или всей страницы.
- Markdown проходит через ограниченный список разрешённых элементов и атрибутов;
  код подсвечивается как текст. Скрипты, стили и обработчики из README не исполняются.
  Изображения из Lessons включаются в сборку. Произвольный HTML из Markdown не поддерживается.
- Оболочка не требует CDN. Сами учебные страницы могут использовать Bootstrap CDN,
  изображения и внешние API; для них по-прежнему может требоваться интернет.
- HTML задач включён в Vite build как отдельные entry points. Сборку открывайте через
  HTTP (`yarn preview`, адрес `/src/index.html`), а не двойным кликом по файлу.

Тесты механизма не требуют решать учебные задания. Проверки решений курса остаются
отдельными: `yarn test "Lessons/01."` и аналогичные команды. Для незавершённых заданий
ожидаются падающие тесты; успешная сборка их не заменяет.
