## Oxlint

Oxlint выполняет статический анализ JavaScript и TypeScript: находит потенциальные ошибки,
небезопасные конструкции и нарушения принятого в проекте стиля кода.

В курсе используются:

- нативные правила Oxlint для JavaScript, TypeScript, импортов и script-блоков Vue;
- type-aware проверки TypeScript;
- совместимые stylistic-правила через JS Plugin.

Проверка шаблонной части `.vue`-файлов не выполняется: текущая версия Oxlint ещё не
поддерживает полный разбор Vue-шаблонов.

## Запуск

Проверить проект:

```bash
yarn lint
```

Автоматически исправить поддерживаемые нарушения:

```bash
yarn lint:fix
```

Не все нарушения можно исправить автоматически. После `lint:fix` повторно запустите
`yarn lint` и разберите оставшиеся сообщения.

Конфигурация проекта находится в корневом файле `.oxlintrc.json`.

Для проверки отдельного файла или каталога можно передать путь напрямую:

```bash
yarn oxlint "Lessons/05. DOM. Events"
```

Для подсветки ошибок во время редактирования установите расширение Oxlint для используемой
IDE и укажите корень репозитория как рабочий каталог.
