## JavaScript 101: значения, переменные и базовый синтаксис

На этом занятии разберём, как JavaScript хранит значения, вычисляет выражения и выбирает,
какие инструкции выполнить. К концу занятия вы сможете написать небольшую функцию
с условиями и циклом, объяснить её результат и проверить его тестами.

Предполагается, что вы уже встречали переменные, условия и циклы в другом языке.
Специальные знания HTML, CSS и Vue пока не нужны. Примеры выполняйте по одному:
одинаковые имена переменных в разных блоках относятся к разным примерам.
Основной маршрут — разделы 1–9. Разделы 10–11 — дополнительное чтение и демонстрации.
Подробно функции, объекты, массивы и `this` изучим на втором занятии, модули — на третьем.

### 1. Что такое JavaScript и где выполняется код

**JavaScript (JS)** — язык программирования. На веб-странице HTML задаёт структуру
содержимого, CSS — оформление, а JavaScript позволяет реагировать на действия
пользователя, обрабатывать данные и обновлять интерфейс. Например, посчитать стоимость
товаров после изменения их количества.

Язык поддерживает несколько стилей программирования: последовательные инструкции,
работу с функциями и объектами. Это называют **мультипарадигменностью**. Эти способы
можно сочетать; подробнее разберём их на третьем занятии.

Код выполняет **среда исполнения**. В браузере есть средства работы со страницей,
в Node.js — например, с файлами. Язык один, но возможности окружения различаются.
Редактор, например VS Code или WebStorm, помогает писать код; его средства запуска
обращаются к среде исполнения. Редактор сам по себе не заменяет браузер или Node.js.

Фреймворк — инструмент организации приложения, а не обязательное условие работы JS.
Сначала будем решать задачи средствами языка и браузера, затем перейдём к компонентам
Vue 3 и общему состоянию с Pinia. Vite уже используется для запуска и сборки проекта;
сейчас достаточно уметь выполнять готовые команды.

#### Hello World!

Откройте инструменты разработчика браузера (**DevTools**) и вкладку **Console**.

командой `node путь-к-файлу.js`. Команды терминала не вводят в браузерную Console,
а браузерный `alert` в обычном Node.js недоступен.

Для разовых экспериментов подходят онлайн-редакторы, например Playcode, CodePen или

### 2. Переменные: const, let и область видимости

Переменная связывает имя со значением. Имя позволяет использовать результат вычисления
несколько раз и объясняет его назначение:

```js
const price = 120;
let quantity = 2;
quantity = 3;
console.log(price * quantity); // 360
```

`const` используйте, когда новое присваивание этой переменной не требуется. `let` —
когда значение нужно заменить, например увеличить счётчик. Знак `=` означает
присваивание, а не проверку равенства. Имена чувствительны к регистру: `price` и `Price`
различаются. Для составных имён используем `camelCase`: `totalPrice`.

`let` можно объявить без начального значения: после объявления это `undefined`.
Для `const` начальное значение обязательно.

```js
let message;
console.log(message); // undefined
message = 'Готово';
console.log(message); // Готово
```

Следующий пример намеренно ошибочный; запускайте его отдельно:

```js
const name = 'Justine';
name = 'Maria'; // Ожидается TypeError: новое присваивание const
```

#### Где доступна переменная

**Область видимости** — участок программы, в котором доступно имя. У `let` и `const`
она ограничена окружающим блоком `{ ... }`, функцией или модулем, если объявление
находится на его верхнем уровне. В обычном скрипте верхний уровень — глобальная область.
Файлы заданий курса являются модулями: их верхнеуровневые имена не общие для всех файлов.

```js
const course = 'JavaScript';
{
    const topic = 'Переменные';
    console.log(course + ': ' + topic); // JavaScript: Переменные
}
// Снаружи блока topic недоступна.
```

Поиск имени идёт из текущей области во внешние. Это **лексическая область видимости**:
доступность имён определяется тем, где код записан. «Лексическая» и «глобальная» —
не два взаимоисключающих вида области. Вторая лекция продолжит эту тему на функциях.

**Проверьте себя:** чем объявление `let quantity = 2` отличается от `quantity = 3`?
Почему `topic` нельзя прочитать после блока? `var` и доступ до объявления разберём в разделе 11.

### 3. Значения и типы данных

Тип определяет, какие данные представляет значение и как с ним работают операции.
В JavaScript восемь типов: семь примитивных и объектный.

| Тип | Что представляет | Пример |
|---|---|---|
| `undefined` | Единственное значение undefined, например после `let message;` | `undefined` |
| `boolean` | Истину или ложь | `true`, `false` |
| `number` | Числа, включая дробные, и специальные значения | `42`, `2.5`, `NaN`, `Infinity` |
| `string` | Текст | `'itis'`, `''` |
| `bigint` | Целые произвольной точности в пределах ресурсов среды | `42n`, `9007199254740993n` |
| `symbol` | Уникальное значение, например для ключа свойства | `Symbol('name')` |
| `null` | Единственное значение null; обычно явное отсутствие данных | `null` |
| `object` | Объекты со свойствами | `{ name: 'Evan' }` |

Массивы `Array`, даты `Date`, регулярные выражения `RegExp`, коллекции `Map` и `Set`,
ошибки `Error` и функции относятся к объектам, а не к дополнительным примитивным типам.
Пока достаточно узнавать их; подробно объекты и массивы понадобятся на следующем занятии.

#### typeof

Оператор `typeof` возвращает строку с информацией о типе значения:

```js
console.log(typeof 42); // number
console.log(typeof NaN); // number
console.log(typeof 42n); // bigint
console.log(typeof 'itis'); // string
console.log(typeof true); // boolean
console.log(typeof undefined); // undefined
console.log(typeof Symbol('name')); // symbol
console.log(typeof {}); // object
console.log(typeof null); // object
console.log(typeof console.log); // function
```

`typeof null` возвращает `'object'` по историческим причинам, хотя `null` — примитив.
Для проверки на `null` сравнивают значение с `null`. Функции — объекты, но `typeof`
выделяет их результатом `'function'`. Массив и обычный объект этот оператор не различает:
для массива есть `Array.isArray(...)`.
[Подробнее о типах](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Data_structures).

#### Number: величина и точность — разные ограничения

Тип `number` использует двоичное представление с плавающей точкой. Диапазон безопасных
целых — от `-(2 ** 53 - 1)` до `2 ** 53 - 1`. В нём целые представлены точно и различимы.
Числа за его пределами тоже существуют, но соседние целые могут уже не различаться.
Это не диапазон всех значений `number`.

```js
console.log(Number.MAX_SAFE_INTEGER); // 9007199254740991
console.log(0.1 + 0.2); // 0.30000000000000004
console.log(Number('не число')); // NaN
console.log(Number.isNaN(Number('не число'))); // true
console.log(1 / 0); // Infinity
```

`NaN` — специальное значение типа `number`, возникающее, например, при неудачном
преобразовании строки в число. Проверяйте его через `Number.isNaN`: сравнение
`NaN === NaN` даёт `false`. Погрешность `0.1 + 0.2` связана с представлением дробей;
способ расчёта и округления десятичных величин нужно выбирать явно.
[Справочник Number](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Number).

`BigInt` нужен для точных целочисленных вычислений, в том числе с большими значениями.
Он представляет и небольшие числа: `1n` допустимо. При арифметике нельзя смешивать
`number` и `bigint` без явного преобразования: `1n + 1` вызовет `TypeError`.
В задачах этого занятия достаточно `number`.
[Справочник BigInt](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/BigInt).

#### Изменение значения и изменение объекта

Примитивы **неизменяемы**: нельзя изменить уже существующее строковое значение.
Можно получить новую строку и присвоить её переменной `let`:

```js
let text = 'itis';
const upperText = text.toUpperCase();
console.log(text); // itis
console.log(upperText); // ITIS
text = upperText;
console.log(text); // ITIS
```

`toUpperCase()` — метод получения строки в верхнем регистре. Он вернул новое значение,
а исходную строку не изменил. Запись `text[2] = 'a'` строку также не изменит; в строгом
режиме, в том числе в модулях курса, она вызывает `TypeError`.

Содержимое обычного объекта менять можно даже через переменную `const`:

```js
const information = { name: 'Evan', surname: 'You' };
information.name = 'Michael';
console.log(information.name); // Michael

const letters = ['a', 'b', 'c'];
letters[3] = 'e';
console.log(letters.length); // 4
```

Здесь изменены свойства объекта и элемент массива. Нового присваивания переменным
`information` и `letters` не было: `const` запрещает именно его, а не изменение содержимого.

При присваивании объект не копируется целиком: копируется значение ссылки на тот же
объект. Поэтому изменения через одно имя видны через другое:

```js
const original = { name: 'Evan' };
const sameObject = original;
sameObject.name = 'Michael';
console.log(original.name); // Michael
console.log(original === sameObject); // true
console.log(original === { name: 'Michael' }); // false
```

Последний объект создан отдельно. Сравнивается идентичность объектов, а не совпадение
их свойств. При передаче в функцию также передаётся значение; для объекта это значение
ссылки. Разберём последствия на втором занятии.

**Самопроверка:** почему изменение `information.name` допустимо, а новое присваивание
`information = {}` — нет? Что вернёт `typeof null` и почему этого недостаточно для проверки объекта?

### 4. Преобразования, арифметика и сравнения

**Динамическая типизация** означает, что переменная не закреплена за одним типом:
при новом присваивании она может получить значение другого типа. Тип есть у значения,
включая `undefined`.

```js
let value;
console.log(typeof value); // undefined
value = 'Justine';
console.log(typeof value); // string
value = 42;
console.log(typeof value); // number
value = true;
console.log(typeof value); // boolean
```

**Неявное преобразование** происходит по правилам операции без отдельного вызова
преобразования. Из-за таких правил JavaScript также называют слабо типизированным.
Для примитивных значений `+` складывает числа, но если один из операндов — строка,
выполняется соединение строк, или **конкатенация**:

```js
console.log(4 + 2); // 6
console.log(4 + '2'); // 42
console.log('4' + 2); // 42
console.log(typeof (4 + '2')); // string
console.log('4' - 2); // 2
```

Движок не угадывает намерение программиста. У `-` нет строковой конкатенации,
поэтому в последней строке `'4'` преобразуется в число. Не любые разные типы
можно соединить без ошибки — пример с `BigInt` выше показывает исключение.

#### Явное преобразование

Если требуется число, преобразуйте текст через `Number(...)`. Для строкового результата
используйте `String(...)`, для логического — `Boolean(...)`.

```js
console.log(4 + Number('2')); // 6
console.log(String(42)); // 42
console.log(typeof String(42)); // string
console.log(Number('')); // 0
console.log(Number('   ')); // 0
console.log(Number(null)); // 0
console.log(Number(undefined)); // NaN
```

Пустой текст превращается в ноль, поэтому для пользовательского ввода сначала нужно
решить, допустима ли пустота. В задаче о билетах `Number('6')` превращает отдельную
цифру из строки в число, которое можно прибавить к сумме.

#### Арифметические операции

| Оператор | Значение | Пример |
|---|---|---|
| `+`, `-` | Сложение, вычитание | `7 + 2` → `9` |
| `*`, `/` | Умножение, деление | `7 / 2` → `3.5` |
| `**` | Возведение в степень | `3 ** 2` → `9` |
| `%` | Остаток от деления | `9 % 2` → `1` |

`%` удобен для проверки делимости: `number % 3 === 0`. Для отрицательных значений
остаток может быть отрицательным: `-9 % 2` равно `-1`. Знак `^` в JavaScript
не возводит в степень: это другой, побитовый оператор.

```js
let count = 10;
count += 1; // То же изменение, что count = count + 1
console.log(count); // 11
count -= 1;
console.log(count); // 10
```

Скобки задают порядок вычислений: `(2 + 3) * 4` равно `20`, а `2 + 3 * 4` равно `14`.

#### Строгое и нестрогое сравнение

`===` проверяет равенство без преобразования типов, `!==` — неравенство.
В задачах курса начинайте с этих операторов: различие числа и строки обычно важно.

```js
console.log(4 === 2); // false
console.log(false === false); // true
console.log(42 === '42'); // false
console.log(42 !== '42'); // true
```

`==` и `!=` используют правила нестрогого сравнения, которые могут преобразовывать типы.
Знать их нужно для чтения существующего кода:

```js
console.log(4 == 2); // false
console.log(1 == true); // true
console.log(0 == false); // true
console.log(42 == '42'); // true
console.log({} == {}); // false
```

Два разных объекта не становятся равными при использовании `==`.
[Подробнее о строгом сравнении](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Strict_equality).
Для проверки порядка есть `<`, `>`, `<=`, `>=`. Следите за типами: две строки сравниваются
как текст, поэтому `'10' < '2'` — `true`, а `Number('10') < Number('2')` — `false`.

**Попробуйте:** предскажите значение и тип результатов `5 + '1'`, `5 + Number('1')`,
`String(5) + '1'`, затем проверьте. Почему одинаковый внешний вид в Console не гарантирует одинаковый тип?

### 5. Строки: свойства, методы и индексы

В задачах нужно менять регистр текста, читать цифры билета и переворачивать строку.
Для этого достаточно нескольких операций:

```js
const text = 'welcome';
console.log(text.length); // 7
console.log(text[0]); // w
console.log(text[text.length - 1]); // e
console.log(text[7]); // undefined
console.log(text.slice(1, 4)); // elc
console.log('js'.toUpperCase()); // JS
console.log('WORLD'.toLowerCase()); // world
```

`length` — **свойство**, его читают без скобок. `slice(...)`, `toUpperCase()` и
`toLowerCase()` — **методы**, их вызывают со скобками. Индексы начинаются с нуля;
`slice(1, 4)` берёт часть строки от индекса 1 включительно до 4 не включительно.
Для пустой строки `length` равно нулю, а элемента с индексом 0 нет.

Для изменения текста собирайте новую строку. Например, добавим префикс и суффикс:

```js
let result = 'JS';
result = '[' + result;
result += ']';
console.log(result); // [JS]
```

Вместо конкатенации можно использовать **шаблонную строку** с обратными кавычками.
В `${...}` подставляется результат выражения:

```js
const name = 'Justine';
console.log(`Привет, ${name}!`); // Привет, Justine!
```

`length` считает кодовые единицы UTF-16 — единицы внутреннего представления строки,
а не всегда видимые символы. Например, `'🙂'.length` равно `2`. Для первых задач
о регистре и перевороте используем латинские буквы, цифры, пробелы и обычную пунктуацию.
Полная обработка Unicode — отдельная тема.
[Справочник строк](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/String).

**Типичная ошибка:** `text.length()` пытается вызвать число как функцию и вызывает
`TypeError`. **Самопроверка:** что получится при `'welcome'.slice(1)`? Как получить последний
элемент непустой строки? Почему `toUpperCase()` не меняет исходную строку?

### 6. Условия и логические операторы

Условие выбирает, какой код выполнить. В цепочке `if / else if / else` выполняется
только первая подходящая ветвь:

```js
const number = 7;
if (number > 10) {
    console.log('Число больше десяти');
} else if (number < 5) {
    console.log('Число меньше пяти');
} else {
    console.log('Число от пяти до десяти включительно');
}
// Вывод: Число от пяти до десяти включительно
```

#### Логическое преобразование

Условие `if` преобразуется в логическое значение. Ложными (**falsy**) являются
`false`, `0`, `-0`, `0n`, `''`, `null`, `undefined`, `NaN`. Остальные обычные значения,
включая `'0'`, `'false'`, `[]` и `{}`, истинны (**truthy**). Историческое исключение
`document.all` для задач курса не нужно.

```js
console.log(Boolean('')); // false
console.log(Boolean('0')); // true
console.log(Boolean('false')); // true
console.log(!true); // false
console.log(!null); // true
console.log(!!1); // true
```

`!` — логическое отрицание, а не арифметический оператор. `!!value` даёт тот же логический
результат, что `Boolean(value)`; явная форма обычно понятнее при первом знакомстве.

#### && и ||

С логическими условиями `&&` означает «и», а `||` — «или»:

```js
const number = 7;
console.log(number > 5 && number < 10); // true
console.log(number < 5 || number > 10); // false
```

Число может быть больше 5 и меньше 10 одновременно. Условие `number > 10 && number < 5`
не выполнилось бы ни для одного числа. Несколько сравнений записывают полностью:
`5 < number < 10` не является проверкой диапазона в JavaScript.

Операторы работают слева направо и могут не вычислять правую часть — это **короткое
замыкание**. `&&` возвращает первый ложный операнд или последний, если все истинны.
`||` возвращает первый истинный или последний, если все ложны. Результат не обязательно boolean:

```js
console.log('' || 'Гость'); // Гость
console.log('Itis' && 'Cool'); // Cool
```

В проверках делимости используйте явные сравнения с нулём.
[Правила &&](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Logical_AND).

#### switch / case

Когда одно значение сравнивается с несколькими вариантами, можно использовать `switch`:

```js
const number = 42;
switch (number) {
    case 35:
        console.log('Число 35');
        break;
    case 52:
        console.log('Число 52');
        break;
    case 42:
        console.log('Число 42');
        break;
    default:
        console.log('Неизвестное число');
}
// Вывод: Число 42
```

Сопоставление с `case` строгое: строка `'42'` не совпадёт с числом `42`.
`break` завершает `switch`. Без него выполнение продолжится в следующих ветвях,
даже если их метки не совпадают. `default` нужен для случая без совпадений.

#### Тернарный оператор

Если нужно выбрать одно из двух значений, есть краткая запись
`условие ? значениеЕслиИстина : значениеЕслиЛожь`:

```js
const number = 42;
const result = number % 2 === 0 ? 'Да, чётное' : 'Число нечётное';
console.log(result); // Да, чётное
```

Для нескольких действий в ветви используйте `if`. Вложенные тернарные операторы
усложняют чтение и для этих задач не нужны.

**Мини-практика:** проверьте условие «от 5 до 10 включительно» на 4, 5, 7, 10 и 11.
В ItisCool число 15 делится и на 3, и на 5: какую проверку нужно выполнить первой?

### 7. Циклы

Цикл выполняет инструкции повторно. Для обработки диапазона удобно явно задавать
начальное значение, условие продолжения и шаг:

```js
let total = 0;
for (let number = 1; number <= 4; number += 1) {
    total += number;
}
console.log(total); // 10
```

В `for` сначала один раз выполняется `let number = 1`. Перед каждой итерацией проверяется
`number <= 4`, затем выполняется тело, после него — шаг `number += 1`.
`total` объявлена снаружи, поэтому сохраняет результат между итерациями.
Если объявлять её заново внутри тела, накопление не получится.

#### break и continue

`break` завершает цикл. `continue` пропускает остаток текущей итерации; у `for` затем
выполняется шаг и снова проверяется условие:

```js
for (let number = 10; number < 42; number += 1) {
    if (number === 15) {
        continue;
    }
    if (number === 20) {
        break;
    }
    console.log(number);
}
// Вывод: 10, 11, 12, 13, 14, 16, 17, 18, 19 — каждый на отдельной строке
```

Число 15 не печатается, потому что `continue` стоит **до** вывода. На 20 цикл завершается.
[Справочник continue](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/continue).

#### while и do...while

`while` сначала проверяет условие, поэтому тело может не выполниться ни разу:

```js
let number = 30;
while (number < 33) {
    console.log(number);
    number += 1;
}
// Вывод: 30, 31, 32 — каждый на отдельной строке
```

`do...while` проверяет условие после тела и выполняет его хотя бы один раз:

```js
let number = 42;
do {
    console.log(number); // 42
    number += 1;
} while (number < 42);
```

**Типичная ошибка:** забыть шаг и получить бесконечный цикл. Внимательно проверяйте
`continue` в `while`: он может пропустить увеличение счётчика.

Циклы `for...of` и `for...in` разберём с массивами и объектами на следующем занятии.

### 8. Math: корни и округление

`Math` — встроенный объект с математическими константами и методами. Константы —
свойства, методы вызываются со скобками:

```js
console.log(Math.E); // 2.718281828459045
console.log(Math.PI); // 3.141592653589793
console.log(Math.abs(-42)); // 42
console.log(Math.sqrt(81)); // 9
console.log(Math.floor(2.7)); // 2
console.log(Math.ceil(2.1)); // 3
console.log(Math.round(2.7)); // 3
console.log(Math.trunc(-2.7)); // -2
console.log(Math.floor(-2.7)); // -3
```

`floor` округляет к меньшему целому, `ceil` — к большему, `round` — к ближайшему
(при равном расстоянии — в сторону большего), `trunc` отбрасывает дробную часть.
На отрицательных числах `floor` и `trunc` различаются.
[Правила Math.floor](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/floor).

В задаче RoundAndRootNumber нужно оставить две цифры после точки с округлением вниз.
Подумайте, как умножение на 100 позволяет применить округление до целого к нужному
разряду, и как затем вернуться к исходному масштабу. Результат функции должен быть строкой.

`Math.random()` возвращает псевдослучайное число **от 0 включительно до 1 не включительно**.
Результат конкретного вызова заранее неизвестен:

```js
const randomValue = Math.random();
console.log(randomValue >= 0 && randomValue < 1); // true
```

Это средство для учебных случайных выборов, а не для создания паролей или токенов.
[Справочник Math.random](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/random).

**Самопроверка:** почему `Math.round` не подходит, если сказано «в меньшую сторону»?
Что вернут `Math.sqrt(0)` и `Math.sqrt(-1)`?

### 9. Функция, результат и тесты задания

Функция объединяет инструкции, выполняемые при вызове. В стартовых файлах используется
стрелочная функция. Пока достаточно понимать её вход и выход:

```js
const repeatText = (text) => {
    return text + text;
};
const result = repeatText('example');
console.log(result); // exampleexample
```

`repeatText` — имя функции; `text` — **параметр**, имя для входного значения в теле.
`'example'` при вызове — **аргумент**, конкретное переданное значение. Фигурные скобки
содержат тело. `return` завершает текущий вызов и передаёт результат вызвавшему коду.
Само объявление функции тело не выполняет.

Функция может принимать несколько аргументов, например `(begin, end)`, или ни одного —
`()`. Если тело с фигурными скобками не выполняет `return` со значением, результат —
`undefined`. Вывод в консоль и возврат результата — разные действия:

```js
const printText = (text) => {
    console.log(text);
};
const result = printText('Привет'); // Привет
console.log(result); // undefined
```

В HelloWorld и ItisCool требуется **вывод**, в остальных задачах лекции — **возврат**.
Не добавляйте `prompt` внутрь проверяемых функций: тест передаёт аргументы сам.
Строка `export default ...` в конце стартового файла делает функцию доступной тесту;
сохраните её. Подробности функций будут в лекции 2, экспортов — в лекции 3.


Первая команда запускает тесты один раз, вторая — повторяет их после изменений.

### 10. Дополнительно: взаимодействие с пользователем

Браузер предоставляет простые диалоги:

- `alert` показывает сообщение;
- `prompt` возвращает введённую строку или `null` при отмене;
- `confirm` возвращает `true` при подтверждении и `false` при отказе.

Диалоги удобны для первых опытов, но прерывают обычное взаимодействие со страницей.
Полноценные интерфейсы позже будем создавать с помощью элементов страницы.
Это браузерные средства, а не часть набора функций обычного Node.js.

Попробуйте в браузерной Console записаться на занятие:

```js
const input = prompt('Сколько мест забронировать?');
if (input === null) {
    alert('Запись отменена');
} else if (input.trim() === '') {
    alert('Введите количество');
} else {
    const quantity = Number(input);
    if (!Number.isInteger(quantity) || quantity <= 0) {
        alert('Нужно целое положительное число');
    } else if (confirm(`Забронировать мест: ${quantity}?`)) {
        alert('Запись подтверждена');
    } else {
        alert('Запись отменена');
    }
}
```

`trim()` возвращает строку без пробелов по краям. `Number.isInteger(...)` проверяет,
является ли значение целым числом. Сначала проверяем отмену, чтобы не обращаться
к методу строки у `null`, затем пустой ввод, и только потом преобразуем в число.
Это демонстрация диалогов: реальные места она нигде не сохраняет.
[Возвращаемое значение prompt](https://developer.mozilla.org/en-US/docs/Web/API/Window/prompt).

**Проверьте вручную:** отмена, пустой ввод, пробелы, `abc`, `0`, `2.5`, `2` с подтверждением
и с отказом. Почему нельзя начать с `Number(prompt(...))`, если важно отличить отмену от нуля?

### 11. Дополнительно: история языка и детали поведения

#### JavaScript и ECMAScript

JavaScript появился в 1990-х как язык сценариев для веб-страниц. **ECMAScript** —
стандарт синтаксиса и поведения языка. Браузерные функции вроде `prompt` описаны отдельно.

Важный рубеж — ECMAScript 2015, или ES6: он добавил `let`, `const`, стрелочные функции
и модули. Это расширение языка, а не замена всех прежних конструкций. Стандарт продолжает
развиваться; изучать JavaScript полезнее через поведение возможностей и их поддержку
в нужных средах, чем через номер «самой последней версии».

**Транспиляция** преобразует исходный код в другой код, например новый синтаксис в более
старый для выбранных браузеров. **Полифилл** добавляет реализацию отсутствующего API,
когда это возможно. Преобразование синтаксиса само по себе не добавляет все новые методы
и не гарантирует поддержку любой возможности. Сборку разберём в лекции 4.
[Об ECMAScript](https://developer.mozilla.org/en-US/docs/Glossary/ECMAScript).

Среди важных свойств языка также остаются автоматическое управление памятью,
прототипная модель объектов и функции как значения первого класса. Первое означает,
что среда сама освобождает память, когда данные больше не достижимы; второе связано
с наследованием свойств объектами; третье позволяет присваивать и передавать функции,
как другие значения. Последние две темы продолжатся в лекциях 2–3.

#### var, всплытие и TDZ

До ES2015 переменные объявляли через `var`; эта конструкция по-прежнему работает.
Её область — функция или верхний уровень скрипта/модуля, но не обычный блок `if` или `for`:

```js
function logDate() {
    for (var i = 0; i < 10; i += 1) {
        var text = 'i = ' + i;
    }
    console.log(text); // i = 9
}
logDate();
```

У `var` объявление обрабатывается до выполнения инструкций в его области и переменная
инициализируется `undefined`. Поэтому чтение до строки присваивания допустимо.
Это называют **всплытием**; строки исходного файла буквально не переставляются:

```js
function logBeforeAssignment() {
    console.log(text); // undefined
    var text = 'Готово';
    console.log(text); // Готово
}
logBeforeAssignment();
```

`let` и `const` тоже учитываются при создании области, но до их инициализации читать их
нельзя. Участок выполнения до инициализации называют **временной мёртвой зоной (TDZ)**.
Следующий пример намеренно вызывает ошибку:

```js
console.log(name); // Ожидается ReferenceError: чтение до инициализации
let name = 'Justine';
```

После `let name;` переменная уже инициализирована значением `undefined` и доступна.
При выходе из блока локальная `let` недоступна — это другая причина `ReferenceError`:

```js
function logOutsideBlock() {
    for (let i = 0; i < 10; i += 1) {
        const text = 'i = ' + i;
    }
    console.log(text); // Ожидается ReferenceError: имя вне области
}
logOutsideBlock();
```

Эти ошибочные примеры запускайте отдельно. После необработанной ошибки оставшаяся
часть текущего выполнения не продолжится. Так проще отличать отсутствующее имя
от чтения до инициализации.
[Подробнее о let и TDZ](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/let).

#### Объектные оболочки примитивов

Почему у примитивной строки есть `length` и `toUpperCase()`? При доступе к свойствам
язык использует объектную оболочку примитива. Это не превращает значение переменной
в объект и не требует «распаковать переменную» после вызова. У `null` и `undefined`
такой оболочки нет: доступ к их свойствам вызывает `TypeError`.

```js
const name = 'Alex';
console.log(name.length); // 4
console.log(typeof name); // string
const num = 42;
const wrappedNum = new Number(42);
console.log(typeof num); // number
console.log(typeof wrappedNum); // object
```

Последние строки показывают **явно** созданную оболочку. Для обычных значений используйте
литералы `42`, `'text'`, `true`, а не `new Number`, `new String`, `new Boolean`:
оболочки имеют объектное поведение при сравнении и логическом преобразовании.
[Строки и оболочки](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/String).

#### Разбор banana — необязательный эксперимент

Сохраним пример, показывающий, почему неявные преобразования заслуживают внимания:

```js
const text = ('b' + 'a' + +'a' + 'a').toLowerCase();
console.log(text); // banana
```

Унарный `+` перед `'a'` пытается получить число и даёт `NaN`. Конкатенация формирует
`'baNaNa'`, затем метод переводит текст в нижний регистр. Это разбор правил языка;
для обычного кода явное преобразование читается лучше.
