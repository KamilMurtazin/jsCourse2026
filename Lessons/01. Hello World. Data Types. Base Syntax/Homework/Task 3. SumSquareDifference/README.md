### Задание

Реализуйте `sumSquareDifference(num)`, которая возвращает разницу между квадратом суммы
и суммой квадратов первых `num` натуральных чисел. Вход — положительное целое;
в базовых проверках `num` не больше 1000, чтобы результаты оставались безопасными целыми
типа `number`. Результат — число.

### Теория

1. Сумма квадратов первых десяти чисел: `1² + 2² + ... + 10² = 385`.
2. Квадрат суммы: `(1 + 2 + ... + 10)² = 55² = 3025`.
3. Искомая разница: `3025 - 385 = 2640`.

```js
sumSquareDifference(1); // 0
sumSquareDifference(5); // 170
sumSquareDifference(10); // 2640
```

### Подсказки и критерии готовности

В цикле сохраняйте отдельно сумму чисел и сумму их квадратов. После цикла выполните
последнее вычисление. В JavaScript возведение в степень — `**`, не `^`.
Проверьте `num = 1` и включение последнего числа: диапазон начинается с 1 и включает `num`.
Не печатайте результат вместо `return`.
