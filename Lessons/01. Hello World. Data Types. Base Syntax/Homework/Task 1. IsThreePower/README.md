### Задание

Реализуйте `isThreePower(num)`, которая определяет, можно ли представить входное число
как `3 ** k`, где `k` — целое неотрицательное число. Вход — безопасное целое типа `number`.
Верните boolean. Ноль и отрицательные числа не являются степенями тройки в этом смысле.

Например, `9` — вторая степень тройки, `81` — четвёртая. Число `1` тоже подходит:
`3 ** 0` равно `1`.

```js
isThreePower(1); // true
isThreePower(2); // false
isThreePower(27); // true
isThreePower(0); // false
isThreePower(-3); // false
```
