### Задание

Реализуйте `reverseString(str)`, которая возвращает новую строку с элементами в обратном
порядке. В базовом задании используйте цикл. Вход содержит латинские и русские буквы, цифры,
пробелы и обычную пунктуацию; регистр и сами символы сохраняются.

```js
reverseString('javascript'); // 'tpircsavaj'
reverseString('elosnoc'); // 'console'
reverseString('a b!'); // '!b a'
reverseString('Привет'); // 'тевирП'
reverseString(''); // ''
```

### Подсказки

Длина — свойство `length`, а последний индекс непустой строки — `length - 1`.
Собирайте результат в новой строке: исходную строку нельзя изменить по индексу.

```js
'welcome'.length; // 7
'welcome'[6]; // 'e'
'welcome'.slice(1, 4); // 'elc'
'welcome'.slice(1); // 'elcome'
```

### Критерии готовности

Возвращается строка, а не сообщение в консоли. Проверьте пустую строку, один символ,
несколько символов, пробелы и пунктуацию. Методы массивов для базового решения не нужны.

```bash
yarn test "Lessons/01." -t "01.h.2"
```

### Дополнительный вариант: рекурсия

Сохраните решение с циклом и попробуйте отдельную рекурсивную функцию. **Рекурсия** —
вызов функцией самой себя для меньшей задачи. Здесь меньшую строку можно получить через
`slice(1)`. Сначала определите результат для пустой строки — условие остановки, затем
подумайте, куда добавить первый элемент после переворота оставшейся части.
Без остановки вызовы не закончатся. Большая глубина вызовов ограничена средой, поэтому
рекурсия здесь — упражнение для небольших строк. Полная обработка emoji и составных
Unicode-символов не входит в базовую задачу.
