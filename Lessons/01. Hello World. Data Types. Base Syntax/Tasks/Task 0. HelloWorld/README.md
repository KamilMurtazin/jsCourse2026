### Задание

Реализуйте функцию `helloWorld()` в `index.js`. При каждом вызове она должна один раз
вывести через `console.log` точный текст `Hello World!` — с заглавными H и W и восклицательным знаком.
Аргументов нет; возвращать значение не требуется. Вывод появится в консоли той среды,
где вы вызываете функцию (браузер или терминал тестов).

```js
helloWorld();
// Вывод: Hello World!
```

### Критерии готовности

- Вывод находится внутри функции и происходит при вызове, а не при загрузке файла.
- На один вызов функции приходится один вызов `console.log` с одним строковым аргументом.
- Сохранены имя функции и `export default`.

Проверка из корня репозитория:

```bash
yarn test "Lessons/01." -t "01.c.0"
```

**Подсказка:** `return 'Hello World!'` возвращает строку, но не печатает её.
**Дополнительно:** вызовите функцию дважды и объясните, почему сообщений стало два.
