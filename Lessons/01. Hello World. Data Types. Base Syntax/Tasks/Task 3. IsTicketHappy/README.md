### Задание

Реализуйте `isTicketHappy(numStr)`. Вход — непустая строка из цифр `0`–`9` чётной длины.
Верните `true`, если сумма цифр первой половины равна сумме цифр второй, иначе `false`.
Длина не ограничена шестью цифрами: допустимы, например, `'33'` и `'2341'`.

```js
isTicketHappy('386926'); // true
isTicketHappy('211003'); // false
isTicketHappy('1552'); // false
isTicketHappy('044503'); // true
isTicketHappy('00'); // true
isTicketHappy('2341'); // true
```

### Подсказки

`length` — свойство длины строки. Доступ по индексу возвращает строку, даже если там цифра:

```js
'welcome'.length; // 7
'060006'[1]; // '6'
Number('6'); // 6
```

Складывайте числа, а не склеивайте строки. Не преобразуйте весь номер в число:
это потеряет ведущие нули и может потерять точность у длинного номера.

### Критерии готовности

Функция возвращает именно boolean. Проверьте билеты длиной 2, 4, 6 и 8, счастливый
и несчастливый билет, ведущие нули. Валидация нечётной длины или посторонних символов
в базовой задаче не требуется: вход соответствует условию.

```bash
yarn test "Lessons/01." -t "01.c.3"
```

**Дополнительно:** сформулируйте политику для некорректного номера и реализуйте проверку
в отдельной функции, не меняя контракт `isTicketHappy`.
