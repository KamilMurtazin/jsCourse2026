### Задание

Реализуйте `changeCase(str)`, которая возвращает новую строку, меняя регистр каждой буквы
на противоположный. В базовом задании вход содержит латинские и русские буквы (включая Ё/ё),
цифры, пробелы и обычную пунктуацию. Символы без регистра сохраняются, как и их порядок.

```js
changeCase('Hello, World!'); // 'hELLO, wORLD!'
changeCase('I loVe itis'); // 'i LOvE ITIS'
changeCase('JS 101!'); // 'js 101!'
changeCase('Привет, Ёж!'); // 'пРИВЕТ, ёЖ!'
changeCase(''); // ''
```

### Подсказки

`length` — свойство длины, индексы начинаются с нуля. Методы регистра возвращают новые строки:

```js
'javascript'.length; // 10
'javascript'[0]; // 'j'
'js'.toUpperCase(); // 'JS'
'j'.toUpperCase(); // 'J'
'WORLD'.toLowerCase(); // 'world'
'W'.toLowerCase(); // 'w'
```

Строку нельзя изменять присваиванием по индексу. Используйте цикл и новую строку-накопитель.

### Критерии готовности

Возвращается строка через `return`, а не сообщение в консоли. Проверьте смешанный регистр,
одну букву, пустую строку, пробелы, цифры и пунктуацию. Ввод корректного типа гарантирован.

```bash
yarn test "Lessons/01." -t "01.c.2"
```

**Дополнительно:** сравните длины `'ß'` и `'ß'.toUpperCase()`.
Почему для произвольного Unicode смена регистра не всегда обратима? Это исследование
за пределами базовых тестов, а не требование переписать решение.
