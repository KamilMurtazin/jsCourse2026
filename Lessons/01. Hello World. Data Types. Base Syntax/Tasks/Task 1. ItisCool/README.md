### Задание

Реализуйте функцию `itisCool(begin, end)`, которая выводит через `console.log` числа
в диапазоне от `begin` до `end` включительно. Оба аргумента — целые положительные числа.
Для каждого числа должен произойти ровно один вызов `console.log` с одним аргументом:

- если число делится без остатка и на 3, и на 5 — строка `ItisCool`;
- иначе, если делится на 3 — строка `Itis`;
- иначе, если делится на 5 — строка `Cool`;
- в остальных случаях — само число, без преобразования в строку.

Если `begin > end`, диапазон пуст и функция ничего не печатает. Возвращать результат не нужно.

```js
itisCool(11, 20);
```

Вывод:

```text
11
Itis
13
14
ItisCool
16
17
Itis
19
Cool
```

### Критерии готовности

Проверьте обычный диапазон, один элемент (`15, 15`), обе границы и пустой диапазон
(`35, 25`). Не выводите весь результат одной строкой или массивом.

```bash
yarn test "Lessons/01." -t "01.c.1"
```

**Подсказка:** остаток от деления вычисляет `%`. Для 15 подходят сразу три описания;
порядок проверок должен обеспечить единственный правильный вывод.
**Дополнительно:** объясните, что пришлось бы изменить для убывающего диапазона.
Основная функция при `begin > end` по-прежнему ничего не печатает.
