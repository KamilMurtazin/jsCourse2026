### Задание

Реализуйте `roundAndRootNumber(num)`. Вход — конечное число типа `number`.
Верните квадратный корень числа **в виде строки**, округлив результат вниз до сотых.
Если число отрицательное, верните строку `'error'`.

### Теория

Квадратный корень из `5843` приблизительно равен `76.43951857`. После округления вниз
до сотых получаем `76.43`, а после преобразования в строку — `'76.43'`.
Не дополняйте результат нулями: для нуля ожидается `'0'`, для четырёх — `'2'`.
Здесь проверяется вычисление, а не форматирование денежной суммы.

```js
roundAndRootNumber(5843); // '76.43'
roundAndRootNumber(18248); // '135.08'
roundAndRootNumber(0); // '0'
roundAndRootNumber(5); // '2.23'
roundAndRootNumber(4); // '2'
roundAndRootNumber(-100); // 'error'
```

### Подсказки

Понадобятся `Math.sqrt`, `Math.floor` и `String`. В стартовом файле уже есть
`ROUNDING_DEGREE = 100`: используйте этот масштаб, чтобы применить округление к сотым.
`Math.round` округляет к ближайшему, а не вниз. `toFixed(2)` также решает другую задачу:
форматирует строку с фиксированными двумя знаками.

### Критерии готовности

Проверьте положительное число с дробным корнем, точный квадрат, ноль и отрицательное число.
Каждый результат — строка. Вычисления выполняются средствами `number` и `Math`;
точная десятичная арифметика для произвольных величин не входит в это задание.
